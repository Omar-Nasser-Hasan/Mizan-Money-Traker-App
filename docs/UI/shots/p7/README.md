- `cash-flow.png` — Cash flow tab, trend, and period comparison cards.
- `spending.png` — Spending tab, category/label switch, payees and weekday cards.
- `balance.png` — Balance tab, cash/net-worth control, currency buckets and exchange-gain note.

The physical-device and 50k/500 ms checks remain in `docs/PHONE_CHECKLIST.md`.
